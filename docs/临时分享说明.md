# 临时分享博客

工具使用 Cloudflare 官方 cloudflared，便携安装在 `.tools/cloudflared.exe`。不需要上传 GitHub、购买域名或修改路由器。工具与分享日志已排除在 Git 仓库之外。

## 开启分享

1. 内容修改后，先双击 `cmd/一键构建博客.cmd`。
2. 构建成功后，双击 `cmd/临时分享博客.cmd`。
3. 等待窗口出现 `https://……trycloudflare.com`，把完整网址发给朋友。

脚本会检查本机的 4321 端口是不是当前博客，必要时启动本地预览，再创建临时分享链接。仅分享构建后的网页，不分享源文件目录。

链接也保存在 `.share/分享链接.txt`。电脑需要保持联网与运行，分享窗口需要保持打开。每次重新启动分享，都可能得到不同的网址。

## 停止分享

在分享窗口按 Ctrl+C，或者双击 `cmd/停止临时分享.cmd`。停止脚本只结束此博客目录内的 cloudflared 程序，不会关闭本地博客预览。

## 访问范围

这是临时公开链接，拿到链接的人可以访问，不能只凭网址识别是不是你的朋友。停止程序后链接失效。后续如需指定朋友邮箱验证，可以再配置访问限制。

工具的下载与完整性校验参考 Cloudflare 官方发布。连接失败时查看 `.share/share.log`，不要将“已生成网址”视为已成功连接；需要实际打开网址确认博客可访问。

[官方 Quick Tunnels 说明](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)
